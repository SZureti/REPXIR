## What this project is
**repxir** is a freshly scaffolded single-page web app built with **Vite 8** and **React 19**. Right now it holds the unmodified `create-vite` React (JavaScript) template: one page with a hero image, a click counter, and links to Vite/React docs and community channels. `react-router-dom` 7 is installed but **not used yet** (no routes, no router provider). See [[Technical Debt]].
